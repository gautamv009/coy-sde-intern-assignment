# Coy SDE Intern Assignment

A swipe-based profile discovery and matching app built for the Coy SDE Intern assignment.

## Features

- Discover profiles
- Like or pass on profiles
- Prevent duplicate swipes
- Store swipe data in SQLite
- Detect mutual likes
- Display matches
- Responsive interface

## Tech Stack

Next.js  
React  
SQLite  
better-sqlite3  
JavaScript  
CSS

```bash
npm install
npm run dev
